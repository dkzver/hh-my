# Интеграция с Bitrix24 через VibeCode

## Текущее состояние

В репозитории сохраняется исходный сервис HH ТЗ Finder. Интеграция добавляется отдельным серверным модулем и не меняет существующий поиск вакансий.

### Реализованный фундамент

- Серверный BFF-модуль `src/bitrix24.js`.
- Проверка сессии, которую VibeCode Gateway передаёт в заголовке `X-Vibe-Authorization`.
- Проверка числового ID сотрудника из `X-Vibe-User-Id`.
- Серверный вызов `GET /v1/me` для получения контекста портала.
- Создание лида через `POST /v1/leads`.
- Проверка наличия `VIBE_APP_KEY` без раскрытия значения ключа.
- Ключ не передаётся в браузер и не хранится в Git.

## Переменные окружения

- `VIBE_APP_KEY` — ключ авторизации приложения с префиксом `vibe_app_`. Хранить только в секретах сервера.
- `VIBECODE_API_URL` — необязательно; по умолчанию `https://vibecode.bitrix24.com/v1`.

Для ключа нужны как минимум разрешения `crm` и `user`. Для встраивания приложения в портал требуется разрешение `placement`.

## API приложения

Все пути ниже имеют префикс `/api/bitrix`.

- `GET /status` — безопасный статус настройки, не выдаёт секреты.
- `GET /me` — проверка сессии сотрудника и получение профиля/портала через VibeCode.
- `POST /leads` — создание CRM-лида. Обязательны `title` и имя либо фамилия.

Запросы `/me` и `/leads` должны приходить через VibeCode Gateway из встроенного приложения. Прямой вызов без доверенных заголовков сессии отклоняется.

## Развёртывание

1. Создать ключ авторизации `vibe_app_` в VibeCode.
2. Выдать минимальные scopes: `crm`, `user`, `placement`; инфраструктурный scope добавляется только ключу, которым действительно создаётся сервер.
3. Добавить `VIBE_APP_KEY` в секреты сервера VibeCode.
4. Развернуть Node.js 20 приложение, порт 3000.
5. Настроить размещение приложения в левом меню Битрикс24.
6. Проверить открытие приложения сотрудником, `GET /api/bitrix/me` и тестовое создание лида.

## Ограничения текущего этапа

Интеграция пока не считается подключённой к реальному порталу: для этого необходимы ключ VibeCode, созданное приложение и настройка размещения. Автоматический импорт откликов и дедупликация ещё не реализованы.
