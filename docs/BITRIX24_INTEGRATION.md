# Интеграция с Bitrix24 через VibeCode

## Текущее состояние

Исходный HH ТЗ Finder сохранён. Интеграция подключена отдельным серверным модулем, поиск вакансий не меняется.

### Реализовано в этой ветке

- Серверный модуль `src/bitrix24.js`.
- Подключение роутера в `server.js` по префиксу `/api/bitrix`.
- Получение сессии из доверенного заголовка `X-Vibe-Authorization`, который передаёт Black Hole Gateway для встроенного приложения.
- Вызовы VibeCode API с парой заголовков `X-Api-Key: vibe_app_...` и `Authorization: Bearer vibe_session_...`.
- `GET /api/bitrix/status` — показывает, настроен ли ключ и присутствует ли сессия, не раскрывая секрет.
- `GET /api/bitrix/me` — получает текущего пользователя, портал и scopes через `GET /v1/me`.
- `POST /api/bitrix/leads` — создаёт CRM-лид через `POST /v1/leads`, проверяет обязательные поля и ограничивает длину текстовых значений.
- Общий JSON-обработчик ошибок API.

## Переменные окружения

- `VIBE_APP_KEY` — ключ авторизации приложения с префиксом `vibe_app_`. Хранить только в секретах сервера.
- `VIBECODE_API_URL` — необязательно; по умолчанию `https://vibecode.bitrix24.com/v1`.
- `HH_USER_AGENT` и `PORT` — существующие настройки HH ТЗ Finder.

Для вызовов CRM требуется scope `crm`; для профиля сотрудника — `user`. Для управления размещением приложения в портале требуется `placement`. Выдавайте только необходимые разрешения.

## API приложения

Все пути ниже имеют префикс `/api/bitrix`.

- `GET /status` — безопасный статус настройки.
- `GET /me` — проверка сессии и получение профиля/портала.
- `POST /leads` — создание лида. Обязательны `title` и имя либо фамилия кандидата. Поддерживаются `phone`, `email`, `post`, `companyTitle`, `assignedById`, `sourceId`, `stageId` и `comments`.

Запросы `/me` и `/leads` требуют запроса из встроенного приложения через VibeCode Gateway. Без корректной сессии возвращается 401.

## Развёртывание и подключение

1. Создать OAuth-приложение VibeCode и ключ `vibe_app_`.
2. Выдать scopes `crm` и `user`; добавить `placement` для размещения в интерфейсе.
3. Добавить `VIBE_APP_KEY` в секреты сервера VibeCode.
4. Развернуть приложение на Node.js 20, порт 3000.
5. Зарегистрировать URL сервера в приложении VibeCode и настроить placement.
6. Открыть приложение в Битрикс24 и проверить `GET /api/bitrix/me`.
7. Создать тестовый лид через `POST /api/bitrix/leads` только после подтверждения портала и разрешений.
