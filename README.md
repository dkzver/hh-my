# HH ТЗ Finder

Веб-приложение для поиска вакансий на HeadHunter и отбора вакансий с подробным техническим заданием.

## Возможности
- Поиск вакансий по ключевым словам (PHP, Node.js, React, JavaScript и др.).
- Получение полного описания вакансии через API HeadHunter.
- Оценка подробности описания по объёму, структуре и техническим маркерам.
- Фильтры по зарплате, опыту, формату работы и наличию подробного ТЗ.
- Ссылка на оригинальную вакансию на HH.ru.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Переменные окружения
- `PORT` — порт HTTP-сервера (Render задаёт автоматически).
- `HH_USER_AGENT` — User-Agent для запросов к API HeadHunter.

Приложение не требует собственной базы данных: результаты загружаются из API HH.ru.
